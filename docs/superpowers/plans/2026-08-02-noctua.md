# Noctua Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy Noctua — a transparent, steerable browser agent (Claude tool-loop + Playwright) with a live three-pane cockpit UI, per the spec at `docs/superpowers/specs/2026-08-02-noctua-browser-agent-design.md`.

**Architecture:** Single Node service: Fastify serves a built React SPA, a REST API, and an SSE stream; Playwright (headless Chromium) runs in-process, one context per run; the agent is an observe→think→act Claude tool-use loop with all events persisted to JSONL (replay for free). LLM is injected behind an interface so integration tests run a scripted fake against a bundled fixture site.

**Tech Stack:** Node 22 (ESM), TypeScript strict, Fastify 5, Playwright (chromium), sharp, @anthropic-ai/sdk, Vitest, React 18 + Vite + Tailwind v4. Fonts self-hosted via @fontsource.

## Global Constraints

- Model: `claude-sonnet-5` by default; env `NOCTUA_MODEL` overrides (demo-day flag: `claude-opus-5`). Thinking: `{type: "adaptive", display: "summarized"}`. Effort: `output_config: {effort: NOCTUA_EFFORT ?? "medium"}`. `max_tokens: 16000`, streaming, `tool_choice: {type: "auto", disable_parallel_tool_use: true}`. System prompt carries `cache_control: {type: "ephemeral"}`.
- Budgets per run: max 40 steps, $1.50 API cost, 15 min wall time. Global: `NOCTUA_DAILY_COST_CAP` (default $20), max 2 concurrent runs.
- Every event is appended to `DATA_DIR/runs/<id>/events.jsonl` before being fanned out to SSE. The UI renders only from events.
- Screenshots: JPEG, resized to 1024px wide via sharp, saved as `DATA_DIR/runs/<id>/shots/<step>.jpg`, referenced by URL — never base64 over SSE.
- Auth: every `/api/*` route except `/healthz` and `POST /api/auth` requires the access-code cookie. `ACCESS_CODE` env, required in production.
- SSRF: agent may only navigate to http(s) URLs resolving to public IPs (`assertSafeUrl`).
- Design tokens (exact, from tryminerva.ai): ivory `#F1ECE6`, ink `#171717`, sand `#E3DCCB`, cream `#FAF7F0`, sage `#4A6B4F`, bronze `#B08D3E`, oxide `#9C3D2E`. Fonts: Instrument Serif (display), Geist (UI), Geist Mono (data). No CDN assets, no gradients, no shadows.
- Copy voice: quiet, editorial, Minerva-adjacent. Agent name is **Noctua**; tagline "Give Noctua a chore. Watch it fly."
- Commit after every green test cycle. Never commit `.env`, `data/`, `node_modules/`.

```ts
import { lookup } from "node:dns/promises"
import { isIP } from "node:net"

const PRIVATE_V4 = [/^10\./, /^127\./, /^169\.254\./, /^192\.168\./, /^172\.(1[6-9]|2\d|3[01])\./, /^0\./]
export function isPrivateIp(ip: string): boolean {
  if (isIP(ip) === 6) {
    const low = ip.toLowerCase()
    return low === "::1" || low.startsWith("fe80:") || low.startsWith("fc") || low.startsWith("fd") || low.startsWith("::ffff:127.")
  }
  return PRIVATE_V4.some((re) => re.test(ip))
}

export async function assertSafeUrl(url: string): Promise<void> {
  let u: URL
  try { u = new URL(url) } catch { throw new Error(`blocked: invalid URL`) }
  if (u.protocol !== "http:" && u.protocol !== "https:") throw new Error(`blocked: protocol ${u.protocol}`)
  const host = u.hostname
  if (host === "localhost" || host.endsWith(".local") || host.endsWith(".internal")) throw new Error(`blocked: host ${host}`)
  if (isIP(host)) { if (isPrivateIp(host)) throw new Error(`blocked: private ip ${host}`); return }
  const addrs = await lookup(host, { all: true }).catch(() => { throw new Error(`blocked: cannot resolve ${host}`) })
  for (const a of addrs) if (isPrivateIp(a.address)) throw new Error(`blocked: ${host} resolves to private ip`)
}
```

Default `saveShot` writes `<log.dir>/shots/<step>.jpg` and returns `/api/runs/<id>/shots/<step>.jpg`.

Loop skeleton (real implementation, condensed here for the plan; keep behavior exactly):
```ts
export async function runAgent(run: Run, llm: LLM, opts: LoopOpts = {}) {
  const { log, control } = run
  const emit = (e: AgentEvent) => log.append(e)
  const setStatus = (s: RunStatus) => { run.status = s; emit({ type: "run_status", status: s }) }
  setStatus("running")
  let bp: Awaited<ReturnType<typeof createBrowserPage>> | null = null
  const findings: Record<string, unknown>[] = []
  const history = new History()
  const system = buildSystemPrompt(run.preset)
  let steps = 0
  const startedAt = Date.now()
  let lastUrl = "", lastFindingCount = 0, stuckTurns = 0, noToolTurns = 0, budgetWarned = false
  try {
    bp = await createBrowserPage()
    while (true) {
      if (control.isStopped()) { emit({ type: "done", outcome: "stopped", summary: partialSummary(findings) }); setStatus("stopped"); return }
      if (control.isPaused()) { setStatus("paused"); await control.waitWhilePaused(); setStatus("running") }
      steps++
      const wallMin = (Date.now() - startedAt) / 60000
      const over = steps > config.maxSteps || run.costUsd > config.maxRunCostUsd || wallMin > config.maxWallMinutes
      if (over && budgetWarned) { emit({ type: "done", outcome: "partial", summary: "Budget exhausted. " + partialSummary(findings) }); setStatus("finished"); return }
      const snap = await capture(bp.page)
      const shotUrl = (opts.saveShot ?? defaultSaveShot(run))(snap.screenshotJpeg, steps)
      emit({ type: "screenshot", url: shotUrl, step: steps })
      if (snap.url === lastUrl && findings.length === lastFindingCount) stuckTurns++; else stuckTurns = 0
      lastUrl = snap.url; lastFindingCount = findings.length
      const notes: string[] = control.drainSteer().map((s) => { emit({ type: "steer", text: s }); return `USER STEERING: ${s}` })
      if (stuckTurns >= 4) notes.push("You appear stuck (no page change or new findings for 4 turns). Reconsider your approach or ask_human.")
      if (over) { notes.push("BUDGET EXHAUSTED — you MUST call finish now with what you have."); budgetWarned = true }
      const observation = [snapshotText(snap), `Findings so far: ${findings.length}`, ...notes].join("\n\n")
      const result = await llm.turn({ system, messages: history.toMessages({ text: observation, screenshotJpeg: snap.screenshotJpeg }), tools: toolDefs },
        (t) => emit({ type: "thinking_delta", text: t }))
      run.costUsd += result.costUsd
      emit({ type: "budget", steps, maxSteps: config.maxSteps, costUsd: round2(run.costUsd), maxCostUsd: config.maxRunCostUsd })
      if (!result.toolName) {
        noToolTurns++
        history.addTurn({ assistantContent: result.assistantContent, toolUseId: null, toolResultText: "No tool was called. Continue with exactly one tool call, or call finish.", summaryLine: `step ${steps}: (narration only)` })
        if (noToolTurns >= 3) { emit({ type: "done", outcome: "partial", summary: "Agent stalled. " + partialSummary(findings) }); setStatus("failed"); return }
        continue
      }
      noToolTurns = 0
      const guarded = isGuarded(result.toolName, result.toolInput)
      if (control.mode === "approve" || guarded) {
        emit({ type: "action_proposed", tool: result.toolName, args: result.toolInput, guarded })
        setStatus("awaiting_approval")
        const decision = await control.requestApproval()
        setStatus("running")
        if (decision === "denied") {
          history.addTurn({ assistantContent: result.assistantContent, toolUseId: result.toolUseId, toolResultText: "The user DENIED this action. Choose a different approach.", summaryLine: `step ${steps}: ${result.toolName} denied by user` })
          continue
        }
      }
      emit({ type: "action_started", tool: result.toolName, args: result.toolInput })
      let outcome: ToolOutcome
      try {
        outcome = await executeTool(result.toolName, result.toolInput, {
          page: bp.page, findings,
          askHuman: async (q) => { emit({ type: "ask_human", question: q }); setStatus("awaiting_human"); const a = await control.askHuman(); emit({ type: "human_answer", text: a }); setStatus("running"); return a },
        })
        if (result.toolName === "record_finding") emit({ type: "finding", data: result.toolInput.data as Record<string, unknown> })
        emit({ type: "action_result", tool: result.toolName, ok: true, summary: outcome.summary })
      } catch (err) {
        const msg = err instanceof Error ? err.message : String(err)
        emit({ type: "action_result", tool: result.toolName, ok: false, summary: msg })
        emit({ type: "error", message: msg, recoverable: true })
        history.addTurn({ assistantContent: result.assistantContent, toolUseId: result.toolUseId, toolResultText: `ERROR: ${msg}. Try a different approach.`, summaryLine: `step ${steps}: ${result.toolName} failed` })
        continue
      }
      history.addTurn({ assistantContent: result.assistantContent, toolUseId: result.toolUseId, toolResultText: outcome.summary, summaryLine: `step ${steps}: ${outcome.summary.slice(0, 90)}` })
      if (outcome.finish) { emit({ type: "done", outcome: outcome.finish.outcome, summary: outcome.finish.summary }); setStatus("finished"); return }
    }
  } catch (err) {
    const msg = err instanceof Error ? err.message : String(err)
    emit({ type: "error", message: msg, recoverable: false })
    emit({ type: "done", outcome: "failed", summary: `Unrecoverable error: ${msg}. ` + partialSummary(findings) })
    setStatus("failed")
  } finally { await bp?.close().catch(() => {}) }
}
```
`partialSummary(findings)` = `"${findings.length} finding(s) were preserved."`. Store `findings` on the run (`run.findings = findings` — add `findings: Record<string, unknown>[]` to the `Run` interface in store.ts).
